Mondo is now Mond

  • The app is called Mond. It updates in place from Mondo 0.5.0. Your settings, App rules, arrangements, Scenes, quicklinks and shortcuts all carry over.
  • Mond moves its folders for you on first launch: Application Support/Mondo becomes Application Support/Mond, and the same for Logs.
  • Open at login moves to Mond if it was on. If Mond doesn't open at login, turn on "Open Mond at login" in Settings › General.
  • With Homebrew, the cask is now `mond`. `brew upgrade` moves the `mondo` cask across. Both the `mond` and `mondo` commands work.

Safer

  • Saved data is never silently lost. If a file can't be read, Mond keeps a copy and writes what happened to ~/Library/Logs/Mond/data-errors.log.
  • Helper tools that fail to start are logged instead of crashing Mond.
  • A missing rules file no longer clears your desktop assignments.

Faster

  • The palette no longer waits for its app list if you open it just after launch.
  • Settings pages draw less.
